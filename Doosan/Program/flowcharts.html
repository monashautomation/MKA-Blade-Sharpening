Descend in Z onto the blade top, push in Y until contact, capture pose minus the known datum. Tuning (probe distances, magnet voltages) lives inside the variant — edit it in the Code tab.

Reads camera X/Y, picks a pass count for a 0.1–0.2 mm step, then alternating-direction passes. Tuning (move_range, pass band, feed) lives inside the variant — edit it in the Code tab.

Place blade & release

          
Retreat angle_pos → grinder_app → grinder_top, lower onto the rack with a Z-force probe, magnets off, return to the rack top.

        

      

    

    


    
    

      
      

        

          
Dispatcher

          
Runs homing if enabled, then loops while not in emergency; on REG_START reads the job, selects grinder/bay, and runs pick → measure → approach → grind → finish for each blade. run_pick/run_grind are generated from the variant tabs.

Key measurements · modbus

    
blade_depth
Y-force collision − blade_zero datum. Drives IR offset, grinder invert (−Z), bevel pivot & calibration plunge.

    
blade_length
blade_left[0] − blade_right[0] from the IR end-stop sweep.

    
cut_depth
depth ÷ passes, constrained to 0.1–0.2 mm; sets per-pass feed.

Key measurements · calibration

    
current_angle
Swept 70° → 10° in 5° steps (12 poses), published to REG_CALIBRATION_ANGLE ×10 each step.

    
blade_depth
Re-used from a prior grind run as the pivot point and the 39 − blade_depth plunge depth.

    
grinder_val
Hard-coded = 2 → uses grinder-2 poses & a −90° grind frame.

    
A pure orientation sweep so the vision system can map measured vs. commanded bevel angle.
